# Play The Mossbound Atlas

Download the Windows x64 ZIP, extract its entire folder, and launch **The Mossbound Atlas.exe**. The adjacent `.pck` contains the game and must stay beside the executable. Everything works offline. The package includes the Wiki, changelog, checksums and license notices.

Choose **Settings → Language** for English, 简体中文, 繁體中文, Español or 日本語. Text changes immediately. Music and effect volumes are separate; fullscreen and reduced camera motion are available.

## Start a journey

Choose a name, an optional seed, a game difficulty and a death rule. **Normal + Easycore** is the default. Game difficulty can change during a journey. Death consequences are fixed for that journey.

Speak to Mara beside the hearth. Gather eight wood and six stone, make and place a workbench, then prepare food and follow the eastern trail. The first waystone needs eight wood, six stone and two amber. Your current objective stays on the HUD and in the journal. Starter tools, food, water, bandages and a supply chest help you begin.

Interact with resources to harvest them using the best appropriate owned tool. Open your backpack to consume supplies or equip gear. Nearby chests contribute crafting materials automatically. Crafting and building menus show station, tier and ingredient requirements. When your pack is full, creature and site rewards remain as a supply bundle in the world.

## Controls

| Action | Keyboard and mouse | Controller |
| --- | --- | --- |
| Move / aim | WASD / mouse | Left / right stick |
| Interact / harvest / reel | E | A |
| Attack / place selected building | Left click | RT |
| Dodge / cancel placement | Space / right click | B |
| Sprint | Hold Shift | Hold left stick click |
| Backpack | Tab | Y |
| Crafting | C | X |
| Building | B or HUD button | Open from HUD/menu |
| Atlas | M | Back / View |
| Cycle carried tools and weapons | 1–4 | LB / RB |
| Use bandage / water | 5 / 6 | Select item in backpack |
| Dismantle empty building at aim | R | Right stick click |
| Pause / back | Escape | Start / Menu |

The atlas supports mouse-wheel zoom and drag panning. Menus support keyboard/controller focus. Mouse input remains useful for atlas panning, searching and entering a journey name. These bindings do not imply that every controller model has been tested on hardware.

## Death and saving

- **Easycore:** return to your home with your belongings.
- **Mediumcore:** carried belongings remain in a recoverable grave. Stored supplies stay at camp.
- **Hardcore:** the character's journey ends permanently. You can still inspect the saved atlas.

The game saves every 60 seconds of active play. Use **Pause → Save** or **Save and return to title** before leaving. Closing the window also attempts a save. Three complete backup generations allow automatic recovery from a damaged primary save. An error is shown if writing fails; a failed quit-save keeps the game open.

On Windows, journeys are in `%APPDATA%\Godot\app_userdata\The Mossbound Atlas\journeys`. Preferences are in the same application-data folder. Saves are separate from the installation, so replacing an extracted release folder does not erase them. Copy the application-data folder when moving to another computer. This release does not import the original prototype's world state.

## More to do

Build gardens, keep fish records, complete traveler requests, earn goodwill, establish courier routes and improve equipment. Each region contains six discovery sites. Restore all five waystones and overcome their wardens to finish the main journey; your world remains available afterward. Expeditions offer repeatable, progressively deeper three-wave challenges.

The included Wiki has crafting tables, creature statistics, building functions and progression details. See [First Steps](wiki/First-Steps.md) or [the Wiki home](wiki/Home.md).

## 中文快速开始

解压整个下载文件夹，运行 **The Mossbound Atlas.exe**，请保留旁边的 `.pck` 文件。在设置中选择简体中文或繁體中文。默认“普通＋轻核”适合初次游玩。先与炉火旁的玛拉交谈，收集木材和石料，制作工作台，再沿东边的小路寻找路碑。WASD移动，E互动，鼠标左键攻击，空格闪避，Tab打开背包，Esc暂停。请在暂停菜单中保存进度。

## 繁體中文快速開始

解壓縮整個下載資料夾，執行 **The Mossbound Atlas.exe**，請保留旁邊的 `.pck` 檔案。在設定中選擇繁體中文。預設「普通＋輕核」適合初次遊玩。先與爐火旁的瑪拉交談，收集木材和石料，製作工作臺，再沿東邊的小路尋找路碑。WASD移動，E互動，滑鼠左鍵攻擊，空白鍵閃避，Tab開啟背包，Esc暫停。請在暫停選單中儲存進度。

## Inicio rápido

Extrae la carpeta completa y abre **The Mossbound Atlas.exe**. Conserva el archivo `.pck` junto al ejecutable. Elige Español en Ajustes. Empieza con Normal + Easycore, habla con Mara junto a la hoguera, reúne madera y piedra y fabrica un banco. Después sigue el sendero del este. WASD mueve, E interactúa, clic izquierdo ataca, Espacio esquiva, Tab abre la mochila y Escape pausa. Guarda desde el menú de pausa.

## 日本語の遊び方

フォルダー全体を展開し、**The Mossbound Atlas.exe** を起動してください。隣の `.pck` ファイルも必要です。設定で日本語を選べます。初めてならノーマル＋イージーコアがおすすめです。炉火のそばのマーラに話しかけ、木と石を集めて作業台を作り、東の道へ進みましょう。WASDで移動、Eで調べる、左クリックで攻撃、スペースで回避、Tabで持ち物、Escで一時停止します。一時停止メニューから保存できます。
