# The Mossbound Atlas development board

The [public GitHub Project](https://github.com/users/ProgrammingWithYagle/projects/2) tracks implemented scope, publication and follow-up work. This repository copy keeps the same scope visible offline. Proposed work is separate from the implemented release.

## Release 1.0 scope

- [x] Replace the prototype runtime with modular world, session, save, activity, combat and UI systems.
- [x] Five regions, five wardens, eight travelers and a complete restoration objective.
- [x] 143 items, 115 recipes, 41 building pieces, six crops, fishing, cooking, charms and nine perks.
- [x] Thirty discovery sites, sixteen rotating requests, supply couriers and repeatable expeditions.
- [x] Five game difficulties and independent Easycore/Mediumcore/Hardcore consequences.
- [x] Multiple save slots, automatic saves, three backups and Hardcore retirement markers.
- [x] Five-language catalogs, bundled regional fonts and an in-game changelog.
- [x] Original art, animation preparation/playback checks, original synthesized score and effects.
- [x] Repository Wiki, build tooling and five required CI job definitions.
- [x] Require pull requests and five passing checks through the active [main ruleset](BRANCH_PROTECTION.md); provide Windows packaging and fresh-extraction verification.

The [release page](https://github.com/ProgrammingWithYagle/Open_World_Survival_RPG_CODEX/releases/tag/v1.0.0) records published downloads and checksums. The live Project publication card changes to Done only after those assets are uploaded and the release is public.

## Next priorities after player feedback

| Priority | Work | Acceptance evidence |
| --- | --- | --- |
| High | Long-duration play sessions on all difficulty/death combinations | Session notes, loss/recovery checks, progression timings and actionable balance changes. |
| High | Native-speaker editorial pass in all four translated languages | Terminology and dialogue review in actual screens, followed by catalog/layout checks. |
| High | Controller and audio hardware matrix | Tested device models, UI focus flows, aim, audio transitions and speaker/headphone listening notes. |
| Medium | More region-specific discovery arrangements and request narratives | Distinct new decisions or interactions, rather than only larger item counts. |
| Medium | Accessibility and input customization | Remapping, UI scaling and contrast settings tested through complete menu flows. |
| Medium | Linux and macOS downloadable builds | Platform-specific native play and packaging checks before a supported release. |

Multiplayer, a colony simulation, mod support and an infinite campaign are outside the implemented release. New systems should preserve save integrity and make their player-facing purpose clear. Do not advertise planned features as present.
